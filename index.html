2026 生化組標準作業程序 (SOP) 快速對照手冊

1. 急生化退件與通報 SOP #01

• Comment 3 記載退件原因，留條碼號班次交接。
• 退伍軍人菌/登革熱陽性須口頭通報感控並登記於委外感控通知單。

2. Cobas c503 養護與警報 SOP #02

• 校正液置於黑色架，品管液置於白色架。
• 每日做 Wash Rack（Slot 2: SysClean, Slot 3: Activator），二者嚴禁混淆。

3. Cobas b 211 故障排除 SOP #03

• SD Wash error/FMS error 處理：Utilities -> Fluid actions -> Wetting routines。
• Wet sample path 抽拉空氣2-3次，無效則「輕打水」，隨後執行 Wash -> Cali。

4. Sebia 故障排除 SOP #04

• Short prime 用於管路排氣/清洗。
• Cup 卡住滑軌需下壓，Rack/Cup 卡住機台應關機手動取出。
• Vacuum error 需換真空管或壓力板，Over flow 需清洗及換 Sensor。
